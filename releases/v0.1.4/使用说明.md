# 桌面盒子 v0.1.4（实验版）

日期：2026-10-09。Windows 11 x64，自包含运行包，无需安装 .NET。直接运行同目录 DesktopBox.App.exe，保留全部配套文件。

## 盒子操作

- 管理页面创建普通盒子或文件夹映射。按住顶部空白或标题拖动位置；右下角调整大小。锁定后禁止拖动与缩放。
- 单击标题直接改名，Enter 保存，Escape 取消，点击别处保存；空名不覆盖原名。⋯ 菜单仍可改名、锁定、切换视图或删除。
- 普通盒子拖入添加虚拟入口，不移动文件、不改属性。来自当前用户桌面或公共桌面的文件实验性隐藏原图标；非桌面文件只添加入口。右键移出、删除盒子或退出恢复原图标。
- 映射盒子绑定真实文件夹并同步刷新。拖入默认逐项移动真实文件，同名冲突拒绝覆盖、保留双方；跨磁盘文件夹移动暂不支持，报错保留来源。
- 支持图标、列表、详细信息三种视图，按名称排序；双击打开、右键在资源管理器显示。
- 删除盒子只删除配置，保留所有真实文件。映射路径被改名、删除或断开时提示失效，可通过 ⋯ 重新绑定。
- 默认 Ctrl+Alt+B 显隐全部盒子，唤出置顶；管理页面可修改快捷键。关闭管理窗口留在托盘，从托盘退出才结束软件。开机启动未启用。

## 全局玻璃设置

所有盒子的透明度统一在管理页面设置，范围 0%–95%，新设置默认 80%；盒子内不再放滑块。新建盒子立即沿用同一全局值。旧版每盒透明度由新的全局值取代，原名称、布局、锁定、文件入口和快捷键保留。

采用真正的逐像素透明窗口、轻微圆角、边缘高光与细描边，减少深灰遮色；风格参考 iOS Liquid Glass，没有复制 Apple 的实时折射算法。文字和图标保持清晰，不随背景淡化。

管理页面另有磨砂浓度滑块，范围 0%–100%，默认 0%（清透玻璃）。它独立控制高斯模糊半径，不靠加深底色模拟。浓度大于 0 时，每 200 毫秒在本机内存采样盒子后方区域，模糊后显示；不保存或上传背景画面，隐藏盒子时暂停采样。

**开启磨砂会影响截图和录屏。** 为避免反复采入自身，盒子在磨砂模式下设置系统捕获排除。遵守该设置的截图或录屏工具通常不会显示盒子；需要截图或录屏展示盒子时，先将磨砂浓度调到 0%。管理页面明确提示，默认清透模式不排除截图。不同捕获工具可能有不同结果，这不是安全保护功能。

受保护的窗口、部分全屏程序、远程会话或图形环境可能使背景采样失败或产生黑色背景，调回 0% 可恢复清透模式。采样与模糊存在性能成本和短暂刷新延迟，盒子数量和面积越大成本越高；尚未承诺所有显示环境兼容。

## 图标隐藏及窗口限制

用户选择继续研发并接受实验兼容限制。单图标隐藏通过官方 IFolderView.SelectAndPositionItems 将图标显示位置移到屏幕外，保存原位置；不移动真实文件，也不改文件属性。需关闭桌面自动排列；软件检测到系统拒绝定位时拒绝该项，不擅自改桌面设置。

桌面排序、Explorer 重启、显示器切换、虚拟桌面或系统升级可能干扰图标位置。运行时定时检查，失败在盒子底部提示。正常移出、删除或退出恢复；后台助手在主程序异常终止后尝试恢复，本机强制终止测试通过。断电、注销或助手同时被结束不能保证立即恢复；下次启动先恢复记录。

配置在 %LOCALAPPDATA%\DesktopBoxLY\v1-settings.json；恢复记录在同目录 icon-recovery.json。恢复失败保留记录，不要删除记录来代替恢复。紧急恢复：先退出软件，在程序目录运行 DesktopBox.App.exe --restore-icons，确保 Explorer 正常且关闭自动排列。

盒子为普通 Windows 窗口，非 Explorer 桌面嵌入。不能保证覆盖安全桌面、锁屏、独占全屏或其他置顶程序。Win+D 等系统窗口操作可能影响显示。已验证本机 Windows 11 专业版 10.0.26300 x64，其他构建、多显示器和虚拟桌面尚未全面验证。
