# v0.1.1 验证与变更记录

日期：2026-10-08；Windows 11 专业版 10.0.26300 x64；项目本地 .NET SDK 10.0.401。最终发布构建成功：零错误、零警告。

本版修复与新增：
- 将拖动区从标题文字扩大到整条顶部客户区，透明背景参与鼠标命中；保留系统边缘缩放区。移动超过系统阈值才拖动，避免单击标题误拖。
- 单击标题内联改名，Enter 保存、Escape 取消、失去焦点保存；空名不覆盖原名。菜单改名也打开同一编辑框。
- 每盒独立背景透明度滑块，0%–85%，默认 40%；保存设置，文字与图标不随之淡化。
- 统一中性灰玻璃底色、透明省略号按钮及悬停样式、圆角编辑框、菜单与滑块。
- 应用图标复制自“装盘&装柜”当前正式版 src/assets/logo.ico，原文件与本项目副本 SHA-256 一致；EXE 编译图标、窗口与托盘统一使用该资源。

验证通过：
- 真实窗口的顶部区域坐标和宽度覆盖客户区（边缘保留 Windows 缩放边框）。
- 内联编辑获得键盘焦点；触发键盘事件检查 Enter、Escape、空名称保护；保存后标题和配置一致。
- 滑块值改变背景透明度；窗口整体透明度保持 1，前景不被淡化；保存后重读确认标题和透明度。
- 图标、列表、详细信息三种视图实际渲染并检查截图。
- 位置锁定、普通盒子关闭后的精确图标位置恢复、文件内容不变。
- 文件及配置 7 项检查、单图标隐藏与文件内容/属性保持、强制终止后的恢复助手检查通过。
- 测试设置和恢复日志隔离在专用临时目录，避免与运行中的用户配置互相覆盖；测试文件已清理。

本版没有人工实测鼠标拖动的完整轨迹；顶部命中区与拖动处理已接入并检查。其他 Windows 构建、多显示器切换、Explorer 重启等兼容性仍沿用实验版限制。此记录不能作为这些环境已通过的依据。
