# 第一版需求与实现

依据用户当前授权，2026-10-08。历史的“重建规格草案”是确认需求前的记录，当前以本表、使用说明及项目记忆为准。

|编号|用户要求|v0.1.0 行为与边界|
|---|---|---|
|1|半透明磨砂、轻微圆角|DWM Acrylic 与圆角；效果受 Windows 透明设置影响|
|2|普通盒子为虚拟入口，不移动文件、无存储目录|只在配置中保存路径；没有盒子存储目录|
|3|映射真实文件夹、同步变化、拖入移动、冲突提示|FileSystemWatcher + 2 秒刷新；逐项移动，同名拒绝覆盖；跨盘文件夹移动报错保留源|
|4|图标、列表、详细信息，按名称排序|三种视图、系统文件图标、名称排序|
|5|全局显隐、唤出浮在当前窗口上方|Ctrl+Alt+B 可改，唤出置顶；安全桌面等无法保证覆盖|
|6|创建两类盒子、删除、锁定/解锁、独立改名|管理窗口及每盒 ⋯ 菜单；锁定限制标题拖动与缩放|
|7|删除盒子保留真实文件|只移除配置，恢复普通盒子图标|
|8|普通盒子收纳后仅盒子显示，移出/删除/退出恢复原图标，文件位置不变|用户接受实验兼容限制；通过官方图标位置 API 移至屏幕外。记录原位置并验证恢复；异常退出助手。自动排列或系统拒绝定位时拒绝该项；系统切换场景尚未全面验证|
|9|映射路径删除/改名提示失效，可重新绑定|底部提示、⋯ 重新绑定；不会静默追踪新位置|

合理默认：布局、设置、视图记忆；可调整大小；双击打开；托盘；可改快捷键。未启用开机启动。普通窗口非 Explorer 子窗口。

测试实测及未验证范围见 releases/v0.1.0/验证记录.md。所有功能声明应保留第 8 项实验条件，不能宣传为任意 Windows 环境可靠隐藏。

## v0.1.1 交互补充（用户要求）

顶部整条区域可拖动；单击名称直接编辑；每盒透明度可调并记忆；统一玻璃背景和右上角按钮外观；应用图标沿用“装盘&装柜”当前正式版原图标。详细变更与验证见 v0.1.1 包内文档。

## v0.1.2 材质补充（用户要求）

所有盒子的透明度统一在管理页面设置；另新增磨砂浓度。默认透明度80%、磨砂0%。真实逐像素透明与细边高光替代固定Acrylic；磨砂为本机内存采样加高斯模糊。开启磨砂影响系统截图/录屏，管理页提示，调回0解除。不是 Apple 动态折射的完整复制。盒子内不再放材质控件。详见新版说明与验证记录。

## 2026-10-09 本地试用补充（v0.1.6）

用户指定先本地测试，测试确认后再上传/发布。三种视图隐藏横竖滚动条但保留滚轮；图标随宽度换行；详细信息表头透明，列宽随盒子调整。管理页统一玻璃样式，新增磨砂采样/列表检查间隔，支持手动输入与常用预设。普通盒子支持系统入口及快捷方式身份，收纳后只在盒内显示，关闭软件后恢复系统桌面。

持续实测否定旧的屏幕外位置隐藏：500毫秒内被Explorer摆回。改为实验桌面替代层，暂时隐藏系统图标层并绘制未收纳图标，保留原图标位置和文件属性；退出与异常终止恢复系统图标层。完整限制见 docs/v0.1.6试用说明.md，验证见 docs/v0.1.6本地验证.md。此前版本记录只作历史，不应把旧即时位置检查宣称为可靠持续隐藏。
