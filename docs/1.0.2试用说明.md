# 桌面盒子 1.0.2 试用版

这是用于本地试用的 Windows x64 自包含版本，解压后运行 `DesktopBox.App.exe` 即可。

## 本版改动

- 盒子最小高度随系统图标尺寸调整，范围为 140–180 DIP。
- 列表和详细信息视图不显示图标缩略图；详细信息名称列只显示文字，名称排序仍可用。
- 盒子内支持多选并成组拖动：可拖到其他盒子、拖出盒子，也可从其他应用拖入。普通盒子间拖动会转移入口，映射盒子按真实文件操作处理；普通盒子支持盒内排序。
- 列表和详细信息视图在自动刷新后保留滚动位置和选择状态。

本包为本地试用构建，尚未发布到 GitHub Releases。应用配置沿用 `%LOCALAPPDATA%\DesktopBoxLY`，会读取原有盒子设置。
