# 桌面盒子 v0.1.0（实验版）

日期：2026-10-08。运行环境：Windows 11 x64，建议 22H2 或更高。包内包含 .NET 运行环境，无需安装 GitHub Desktop、Visual Studio 或 .NET。

## 使用

直接运行同目录 `DesktopBox.App.exe`，请保留整个目录内的配套文件。

1. 管理窗口点击“普通盒子”或“文件夹映射”。
2. 拖动盒子标题调整位置，右下角调整大小；⋯ 菜单可改名、锁定、切换视图或删除。
3. 普通盒子：拖入添加虚拟入口，文件不移动、不改属性。来自当前用户桌面或公共桌面的文件，会实验性隐藏原图标。非桌面文件仅添加入口。
4. 映射盒子：拖入默认移动真实文件，逐项处理；同名项目报错并保留双方，绝不覆盖。成功项目仍保留，失败列表单独提示。文件夹跨磁盘移动暂不支持，会报错并保留原文件夹。
5. 双击打开真实文件或文件夹。右键可在资源管理器中显示；普通盒子右键“移出盒子”恢复原图标，文件位置不变。
6. 删除盒子只移除配置，保留所有真实文件；普通盒子恢复所收纳的原图标。
7. Ctrl+Alt+B 隐藏/显示全部盒子，唤出时置顶；管理窗口可修改快捷键。系统占用时提示，保留原设置。
8. 管理窗口关闭后留在托盘；从托盘“退出”正常结束并恢复图标。开机启动未启用。
9. 映射文件夹被改名、删除、断开或无权访问时提示失效，可通过 ⋯ 重新绑定。

配置仅保存在 `%LOCALAPPDATA%\DesktopBoxLY\v1-settings.json`，不上传文件或设置。布局、盒子名称、视图、锁定状态、虚拟入口与快捷键会记忆。每个桌面文件只能收纳到一个普通盒子。

## 单图标隐藏的机制与限制

用户已选择继续研发，并接受兼容性限制。实现通过 Explorer 的 IFolderView.SelectAndPositionItems 将指定图标移至可见区域之外，保留原位置记录；没有移动真实文件，也没有改文件属性。这是“隐藏显示位置”的实验方案，并非 Windows 提供的逐文件隐藏标志。

必须关闭桌面“自动排列图标”。软件检测到自动排列或系统限制位置时拒绝收纳该项，并说明原因；不会擅自更改桌面设置。图标依然属于 Explorer，桌面排序、刷新、重启、显示器变化、虚拟桌面或系统升级可能影响效果。运行期间定时检测并尝试保持隐藏，失败会在盒子底部提示；尚未逐一验证所有这些场景。

正常移出、删除盒子或退出会恢复原位置。主程序异常终止时，后台恢复助手尝试恢复；本机强制终止测试通过。断电、系统注销、恢复助手一并被结束等情况无法保证立即恢复，下次启动先读取恢复记录并恢复。记录为 `%LOCALAPPDATA%\DesktopBoxLY\icon-recovery.json`，恢复失败时保留记录。

紧急恢复：先退出软件，在此目录运行 `DesktopBox.App.exe --restore-icons`。若失败，关闭自动排列，确保 Explorer 已启动，再运行。不要删除恢复记录来代替恢复。

当前已验证：Windows 11 专业版 10.0.26300 x64，本机正常桌面环境。尚未承诺兼容所有 Windows 构建、桌面扩展、自动排列设置、多显示器切换或虚拟桌面。

## 外观与窗口范围

采用 Windows DWM Acrylic 背景和轻微圆角，透明效果受系统“透明效果”、对比度主题和图形环境影响，关闭系统透明效果时可能退化为纯色。DWM 系统背景接口要求 Windows 11 Build 22621 或更新。

盒子为普通 Windows 窗口，快捷键唤出会置顶。不能覆盖 UAC 安全桌面、锁屏，不能保证覆盖独占全屏或其他置顶程序。此版没有把窗口嵌入 Explorer 桌面，Win+D 与其他系统窗口操作可能影响显示。
