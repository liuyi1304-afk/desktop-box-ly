# 桌面盒子 1.0.12 正式版

- 图标视图使用 Windows Shell 返回的桌面图标网格间距作为图标单元尺寸，并按屏幕 DPI 换算。盒子变窄或内容区变小时，单元会收缩以适配可用空间。
- 盒子最小高度调整为 100。
- 使用全局快捷键显示或隐藏盒子时加入淡入上浮、淡出下沉动效。
- 保留此前版本的文件拖动、多选、缩略图和视图布局功能。

完整解压后运行 `DesktopBox.App.exe`，无需另装 .NET。快捷键默认 Ctrl + Alt + B。

- 桌面图标层支持将图标拖到桌面空白处重新定位，并吸附到 Windows 网格；与盒子或其他图标冲突时会移到最近空位。
