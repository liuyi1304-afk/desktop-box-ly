状态：草案，依据 GitHub 仓库当前唯一的 README 整理；细节尚未由用户确认。

## 现状

GitHub 仓库目前只有 README、LICENSE 和 `.gitignore`，没有应用源码、安装包、截图或后续提交。README 将产品描述为面向 Windows 11 的 WinUI 3 / C# 桌面盒子管理器原型，目标包括可配置的半透明盒子、文件夹映射和文件操作。

## 建议的第一版目标

在 Windows 11 桌面上显示多个可移动、可调整大小的半透明盒子。每个盒子关联一个用户选择的本地文件夹，用盒子标题和文件列表帮助用户分区整理桌面内容。

第一版建议支持：

- 新建、删除和配置盒子：名称、关联文件夹、透明度和颜色。
- 在桌面上拖动和调整盒子大小；重启后恢复盒子和位置。
- 浏览关联文件夹中的内容；双击文件打开，双击文件夹进入，提供“在资源管理器中打开”。
- 提供刷新和更换映射文件夹的入口。
- 设置保存在本机用户配置目录，不上传文件名或文件内容。

## 暂缓确认的行为

README 只写了“文件操作”，没有定义具体范围。复制、移动、重命名、删除和拖放导入会改变用户文件，因此不应默认擅自实现。建议第一版先只展示、打开和定位文件；确定操作边界后再加入对应命令，并明确撤销或回收站行为。

开机自启、多显示器布局、云同步、自动分类和文件内容索引也未在现有说明中出现，暂不纳入第一版。

## 技术路线

仓库说明指定 C# + WinUI 3，先沿用该路线。当前工作电脑没有 .NET SDK / Visual Studio / MSBuild；需要在项目本地准备 Windows 应用构建工具后才能编译验证。

## 第一版验收建议

1. 可以创建至少两个不同的盒子并映射不同文件夹。
2. 盒子可移动、缩放、改变透明度；设置重启后仍在。
3. 文件列表与映射文件夹内容一致；打开和定位动作有效。
4. 未明确授权的操作不会修改或删除文件。
5. 在目标 Windows 11 电脑上可编译、启动和打包。
