# 桌面盒子 1.0.5 正式版

Windows x64 自包含版本，解压后运行 `DesktopBox.App.exe`，无需另装 .NET。

## 本版改动

- 支持接收微信等应用提供的虚拟文件拖放数据，并把文件保存到盒子或映射文件夹。
- 收紧详细信息视图中类型、大小和修改时间列的宽度。
- 文件大小按 B、KB、MB、GB、TB 自动换算显示。
- 快捷键唤出盒子时只将盒子显示到前台，不再强制“总在最前”；切换到其他应用后，其他窗口可以正常覆盖盒子。
- 保留 1.0.4 的列表/详细信息缩略图、较小盒子高度、滚动位置保持和多选拖动。

应用配置沿用 `%LOCALAPPDATA%\DesktopBoxLY`，会读取原有盒子设置。
