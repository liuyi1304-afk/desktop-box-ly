# v0.1.8 本地崩溃修复

Windows应用日志证实v0.1.7在桌面替代层鼠标拖动中，Shell解析入口返回找不到文件，未处理的FileNotFoundException导致退出。

修复：只允许从该图标明确按下左键开始拖动，按下捕获鼠标，松开/失去捕获清除状态；拖动前校验入口存在，捕获文件/系统入口失效的异常，取消该次拖动并请求下次刷新；不删除或移动用户文件。保留v0.1.7的图标大小、半透明框及尺寸吸附。

实测：已删除TXT和无效Shell入口被安全拒绝，有效快捷方式仍能生成并读回拖动数据；真实桌面隐藏、图标尺寸与退出恢复通过；强杀恢复通过。测试创建的DesktopBox专用桌面文件已自动清理，用户配置未含测试文件。用户报告临时TXT，具体文件名尚待确认；不能据此断言就是测试文件。

本地试用，未经用户确认不上传或发布。
