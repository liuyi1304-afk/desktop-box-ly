# 桌面盒子 1.0.0 正式版

Windows 11 桌面收纳工具。下载 Windows x64 压缩包，完整解压后运行 `DesktopBox.App.exe`，无需另装 .NET。

- 普通盒子收纳桌面入口，隐藏重复原图标并在退出后恢复；支持四边调整大小、边缘吸附、拖动盒子内图标排序。
- 映射盒子同步显示真实文件夹，详细信息支持名称、类型、大小和修改时间升降序；文件夹拖入按系统文件操作移动。
- 图标、列表和详细信息视图，支持系统入口如回收站、网络和控制面板。
- 统一半透明玻璃外观，管理页提供透明度、磨砂和刷新间隔设置。
- 配置保存在当前 Windows 用户目录，换版本或卸载前可备份 `%LOCALAPPDATA%\DesktopBoxLY`。

桌面图标层使用系统 Shell 项目菜单，依赖 Explorer 及 Shell 扩展，少数系统入口可能只提供有限选项。自包含 Windows x64 版本。
