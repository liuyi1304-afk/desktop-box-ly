# 桌面盒子 v0.1.6 本地试用版

日期：2026-10-09。此版只供本地测试，未经用户确认不上传、不公开发布。

完整保留同目录配套文件，运行 DesktopBox.App.exe。原配置继续使用，本轮试用前已备份到项目 output 目录。

- 所有视图隐藏横向和竖向滚动条，鼠标滚轮仍可滚动；图标随盒子宽度换行。
- 详细信息四列随宽度调整，表头采用透明背景。
- 管理页采用与盒子一致的玻璃、圆角及按钮，单击右上角 × 隐藏管理页；托盘可重新打开。顶部可以拖动。
- 全局透明度、磨砂浓度同时应用到盒子、管理页和选项菜单。磨砂默认0；磨砂大于0时，系统截图和录屏通常不显示这些窗口。背景采样只在本机内存使用，不保存或上传。
- 磨砂采样间隔可输入50–5000毫秒，默认200毫秒；列表检查间隔可输入250–60000毫秒，默认2000毫秒。可以从‘常用’选择预设，输入后按Enter或离开输入框保存。实际采样速度受机器负载影响；文件夹也会响应系统变化通知。
- 普通盒子接受文件、快捷方式及系统入口（回收站、网络、控制面板），只保存入口，不移动文件、不修改文件属性。双击打开。右键‘移出盒子’会重新显示桌面入口。
- Windows会迅速把屏幕外图标摆回，旧的单图标屏幕外隐藏机制已停用。新版使用实验桌面图标替代层：软件运行且有桌面入口收纳时，暂时隐藏系统原图标层，按原位置显示未收纳图标；已收纳项只在盒子中显示。正常退出或异常终止恢复助手会重新显示系统图标层，不改变原图标位置。不存在相关桌面收纳时使用系统原图标层。
- 替代层目前提供双击打开、拖入盒子及简化右键菜单；完整Explorer图标多选、原生右键菜单等尚不等同系统桌面。Explorer重启、多屏和不同DPI仍有兼容限制，需用户试用反馈。
- 文件夹映射显示真实目录。拖入会移动真实文件；同名冲突拒绝覆盖，跨磁盘文件夹移动暂不支持。删除盒子保留文件。
- 默认全局快捷键Ctrl+Alt+B，可改；唤出置顶不保证覆盖安全桌面或独占全屏。

配置与恢复文件：%LOCALAPPDATA%\DesktopBoxLY。不要手动删除恢复记录来冒充恢复。需要紧急恢复时，先退出软件，再运行 DesktopBox.App.exe --restore-icons。
