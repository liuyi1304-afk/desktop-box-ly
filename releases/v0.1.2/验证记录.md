# v0.1.2 验证与变更记录

日期：2026-10-09；Windows 11 专业版 10.0.26300 x64；SDK 10.0.401。发布构建零错误、零警告。

本版增加全局透明度及磨砂浓度，移除每盒滑块；采用真实逐像素透明、圆角和高光，新增自绘缩放手柄。磨砂默认关闭，启用时使用本地内存背景采样与高斯模糊，影响系统截图/录屏；管理页面提示。

通过检查：
- --self-test：7 项文件与配置检查。
- --ui-test：全局透明度更新普通、映射及新建盒子；保存重读；标题编辑焦点、Enter、Escape、空名保护；顶部命中区域；透明窗口及缩放手柄拖动事件；位置锁定；三种视图与管理页面渲染；普通盒子关闭后精确恢复图标位置，文件内容保持。
- --glass-test：只在自建蓝白条纹窗口上采样。增加磨砂后，渲染条纹红色通道的方差由 7146.20 降至 0.77（低于原值 25%）；遮色 alpha 保持 13，模糊半径独立升至 30；中部 alpha 小于 255，圆角像素 alpha 为 0；材质设置保存重读正确。

玻璃测试图片只包含程序自己的条纹，不包含用户桌面或其他应用画面。测试配置和恢复日志隔离在专用临时目录，测试文件已清理。捕获排除的基础行为也在受控背景上验证。

未验证完整人工鼠标拖动轨迹、其他 Windows 构建、录屏工具逐项兼容性、受保护背景、远程会话、多显示器切换及长期性能。图标隐藏仍沿用实验版限制。旧版本保留。

补充：复查发现部分GDI屏幕帧的透明通道为0，原ARGB转换会把背景填白。改为32位RGB不透明采样，修复后连续三次磨砂测试通过，相同条纹变化方差均为7146.20→0.77。
